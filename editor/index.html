This page needs to be running through its server

It looks like this file was opened directly in the browser (the address bar doesn't say localhost). The editor needs its small Python server running to read and save anything. From a terminal, in the editor folder, run: 

python3 server.py

Then open the address it prints — usually http://localhost:8420 — instead of double-clicking this file.
